# -Propagation-of-dependencies
Есть некоторое множество измерений, характеризующееся: датой измерения, координатой измерения (на Земле), % содержанием определенных маркеров в измерении. Маркеры измерения состоят друг к другу в иерархической взаимосвязи. Предложить программу визуализации набора маркеров на карте Земли по фильтрам маркеров и времени.
